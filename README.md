# ClassDesk

This is the frontend for ClassDesk, a class manager dashboard. It covers the UI only: pages, components, styling, and page transitions. It is built with Next.js, React, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.
